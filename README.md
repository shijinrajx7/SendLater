# SendLater - schedule WhatsApp messages (Android)

## Build the APK
1. Install Android Studio (Koala or newer). Open the `SendLater` folder (File > Open).
2. Wait for Gradle sync to finish (first sync downloads dependencies, needs internet).
   If it asks about a Gradle wrapper or JDK, accept the defaults (JDK 17 is bundled).
3. Build > Build Bundle(s) / APK(s) > Build APK(s).
   File: app/build/outputs/apk/debug/app-debug.apk
4. Copy the APK to your phone and install it (allow "install unknown apps" when asked).
   Or plug the phone in with USB debugging on and press Run.

## First run
- Allow notifications, exact alarms, and contacts when asked.
- Settings > set battery to Unrestricted for SendLater.
- Optional auto mode: Settings > Auto > follow the accessibility steps.
